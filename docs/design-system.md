# نظام تصميم صَنْعة

## الاتجاهات المقترحة

1. **التحريري الفاخر — المختار:** صور واسعة، ألوان ترابية محايدة، عناوين عربية واضحة، أخضر مقتصد. يربط جودة الحرفة بقصة صاحبها ويجعل المنتجات محور التجربة.
2. **السوق المجتمعي الدافئ:** مساحات لونية أدفأ وصور للأشخاص وقصص أقصر؛ مناسب لبناء الانتماء لكنه أقل هدوءاً عند كثرة المنتجات.
3. **الرقمي المبسّط:** بحث وفلاتر كثيفة وبطاقات موحدة، مناسب لاحقاً للوحات الإدارة لكنه أقل تعبيراً في الصفحة الرئيسية.

## الأسس

- الأساسي: `#008655`، النص: `#17211D`، الخلفية: `#F6F8F7`، الحدود: `#E4EAE6`، الأبيض: `#FFFFFF`.
- خط IBM Plex Sans Arabic؛ بديل sans-serif عند غياب الشبكة. العناوين 25–66 بكسل حسب الشاشة. نصوص المحتوى 12–15 بكسل.
- المسافات الأساسية: 4، 8، 12، 16، 24، 32، 48، 64 بكسل.
- انحناء البطاقات 8 بكسل، الحوارات 16 بكسل. الظلال خفيفة فقط.
- تخطيط سطح المكتب أربع بطاقات، والهاتف بطاقتان، مع تحول قسم القصة إلى عمود واحد.
- حدود تركيز مرئية، نصوص بديلة للصور، تسميات للحقول والأزرار، حوار HTML أصلي، `aria-pressed` للفلاتر والمفضلة، واحترام تقليل الحركة.
- لا شارة حكومية. عبارة «تحقق تجريبي» تعني المحاكاة فقط.

## مراجعة المكتبات

جرى الوصول إلى بيانات README وتراخيص المستودعات الأربعة عبر GitHub API في 2026-11-16: shadcn-ui/ui، magicuidesign/magicui، ibelick/motion-primitives، saadeghi/daisyui. التراخيص الأربعة MIT. هذه مراجعة أولية للملفات والتراخيص وليست تدقيقاً لكل مصدر أو مكوّن. لم تُنسخ مكونات منها؛ استُخدمت مكونات React وCSS أصلية وأيقونات Lucide تحت ISC. أُجّل Tailwind وMotion لتقليل الاعتماديات في نموذج المرحلة الأولى.
