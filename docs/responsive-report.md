# تقرير التجاوب — الصفحة الرئيسية لصَنْعة

النطاق: الصفحة الرئيسية `/` وأقسامها، القائمة، البحث، الفلاتر، المفضلة وحوارات التفاصيل. لا توجد حالياً صفحات مستقلة للمتاجر أو الحسابات أو لوحات الإدارة؛ لا يشمل هذا التقرير صفحات لم تُبنَ بعد.

## التغييرات

- حافظ الكمبيوتر والآيباد الأفقي على ترتيب الترويسة وHero ذي العمودين والبحث الأفقي والقصة ذات العمودين.
- الهاتف يستخدم Hero وقصة وبحثاً بعمود واحد، ومنتجات بعمودين ومتاجر بعمود واحد. عند 320 بكسل تنخفض المنتجات إلى عمود واحد.
- شبكات مرنة مع `minmax()` و`auto-fit` و`clamp()`، دون تحجيم الصفحة بـ transform: scale ودون إخفاء تجاوز الصفحة كحل شكلي.
- أزرار الأيقونات والمفضلة والتنقل والفلاتر بأهداف لمس لا تقل عن 44×44 بكسل؛ حقول البحث والاختيار بخط 16 بكسل.
- قائمة قابلة للطي أسفل 950 بكسل، مرتبطة بأسفل الترويسة بدلاً من إزاحة ثابتة؛ ارتفاع قابل للتمرير وفق المساحة الرأسية.
- حوارات محدودة بارتفاع `100dvh - 32px`، وصور متناسبة، وقاعدة خاصة للشاشات القصيرة، ودعم تقليل الحركة.
- إصلاح التصاق كلمتين عند إخفاء فاصل السطر على الهاتف.
- رصد فشل تحميل الخط من Google Fonts في سجل Chromium؛ استبدال الاستيراد الخارجي بملفات خط محلية مع ترخيص OFL.

## الاختبارات الفعلية

استُخدم Chromium المثبت مع Playwright Core على ملفات تصدير الإنتاج. اعتراض طلبات `http://sanaa.test/` يعيد الملفات المحلية نفسها، دون خادم تطوير أو اعتماد على اتصال الموقع المنشور. توجد صور كاملة قبل التفاعل وبعده ونتائج JSON في `work/responsive-qa/`، وأداة قابلة لإعادة التشغيل: `npm run test:responsive`؛ يمكن تحديد `CHROMIUM_PATH`.

| المقاس CSS px | DPR المحاكى | أعمدة المنتجات | أعمدة المتاجر |
|---|---:|---:|---:|
| 1920×1080 | 1 | 4 | 3 |
| 1440×900 | 1 | 4 | 3 |
| 1366×768 | 1 | 4 | 3 |
| 1024×768 | 2 | 3 | 3 |
| 820×1180 | 2 | 2 | 2 |
| 390×844 | 3 | 2 | 1 |
| 360×800 | 3 | 2 | 1 |

حالتان إضافيتان: 683×384 (مساحة CSS المتاحة تقريباً عند تكبير شاشة 1366×768 إلى 200%) و320×600. هذه محاكاة إعادة تدفق وليست اختبار زر التكبير في متصفح نظام تشغيل. كثافة البكسلات محاكاة وليست اختباراً على أجهزة حقيقية.

يشمل الفحص الآلي: عرض المستند مقابل نافذة العرض، تجاوز حدود العناصر، اتجاه RTL، أبعاد أهداف اللمس، أخطاء JavaScript ووحدة التحكم، تبديل المفضلة، فتح الحوار وإغلاقه بلوحة المفاتيح، ملاءمة الحوار للشاشات القصيرة، فتح قائمة الهاتف واختيار رابط، وفلترة الإمارة.

الحدود: محرك Chromium فقط؛ لا يغطي Safari أو Firefox أو لوحة مفاتيح هاتف حقيقية أو قارئ شاشة أو أجهزة فعلية. هذه النتائج تحقق للنطاق المنفذ، وليست ضماناً لكل متصفح وجهاز.

النتيجة النهائية: نجحت الحالات التسع دون تجاوز أفقي أو أهداف تفاعلية أقل من 44×44 بكسل أو أخطاء JavaScript/console. نجح البناء وفحص الأنواع. تقرير آلي تفصيلي محفوظ في public/qa/results.json. أُضيف اختبار قابل للتشغيل عبر npm run test:responsive، ويتطلب Chromium مثبتاً أو تحديد CHROMIUM_PATH. لقطات الاختبار تُحفظ في work/responsive-qa ولا تُرفع للمستودع.

## تحديث قابلية القراءة

رُفعت نصوص المحتوى إلى 18 بكسل، وأزرار التنقل والفلاتر إلى 16 بكسل، وعناوين المنتجات إلى 17 بكسل، والنصوص المساعدة إلى 14 بكسل باستخدام rem. عُدّلت ألوان النصوص الرمادية إلى لون أوضح مع زيادة تباعد الأسطر. تتوزع روابط التنقل في صف إضافي عند ضيق مساحة الكمبيوتر/الآيباد، وتحافظ الهواتف على القائمة القابلة للطي. لم تُصغّر الصفحة ككل.
