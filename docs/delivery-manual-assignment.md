# الإسناد اليدوي للتوصيل — تقرير التنفيذ والتحقق

## تشغيل الميزة

1. من الإدارة افتح `/admin/delivery/companies` وأضف الشركة، وسعتها اليومية وأيام وساعات العمل الفعلية بتوقيت الإمارات. تطابق وقتي الفتح والإغلاق يعني 24 ساعة في أيام العمل المحددة. اعتماد الشركة لا يمنحها ترخيصاً حكومياً.
2. من تفاصيل الشركة أضف حساباً موجوداً بالفعل وعيّن دوره، ثم جهّز الخدمة والتغطية الدقيقة للطرفين والعقد وقاعدة السعر وحدود الوزن والحجم. صلاحية `delivery.manage` مطلوبة للإعدادات الإدارية.
3. افتح `/admin/delivery/orders`. تظهر فقط طلبات البائعين المدفوعة والمؤكدة/قيد التجهيز/الجاهزة التي لم تُنشأ شحنة لها. عدم وجود طلبات مؤهلة ينتج حالة فارغة حقيقية.
4. جهّز القياسات وعنوان الاستلام والجاهزية والمواعيد. اعتمد عرضاً مؤهلاً يطابق رسوم التوصيل المثبتة في الطلب، ثم أنشئ الشحنة.
5. من `/admin/delivery/shipments/:id` اختر الشركة والخدمة المؤهلتين وحدد مهلة 1–60 دقيقة وسبب القرار. إعادة الإسناد تستبدل العرض السابق مع تأكيد وسجل تدقيق، ولا تغيّر رسوم العميل.
6. يدخل مسؤول الشركة أو العمليات إلى `/delivery/dashboard` ثم `/delivery/shipments/:id` لقبول العرض أو رفضه مع السبب. لا يمكن قبول عرض منتهي أو مستبدل أو قبول شحنة تخص شركة أخرى. الموزع لا يملك القبول والرفض، ودور المندوب لا يدخل بوابة الشركة في هذه الدفعة.

لا تُعرض تفاصيل العنوان الكاملة إلا للإدارة أو للشركة صاحبة الإسناد الحالي المقبول. تبقى للشركة السابقة تفاصيل عرضها التاريخية المحدودة فقط، دون بيانات الشركة الجديدة أو عناوين التشغيل.

## الاختبارات الفعلية — 23 نوفمبر 2026

- `npm run typecheck`: نجح.
- `npm run build`: نجح، بإعداد TanStack/Vite/Nitro الحالي.
- `npm test` مع قاعدة PostgreSQL محلية معزولة: 31 اختباراً ناجحاً في 6 ملفات، منها 17 اختبار قاعدة بيانات حقيقية. بدون متغير قاعدة الاختبار تُتخطى اختبارات القاعدة صراحةً، ولا يُعد ذلك نجاح اختبار الاتصال.
- Chromium بواسطة Python Playwright: 18 فحص تنقل لزائر غير مسجل نحو المسارات المحمية، وكلها تنتهي إلى تسجيل الدخول. 14 فحص تجاوب/لغة عند 1920×1080 و1440×900 و1366×768 و1024×768 و820×1180 و390×844 و360×800؛ لم يظهر تجاوز أفقي أو أخطاء JavaScript على الصفحات المختبرة. استُخدم خادم كتالوج فارغ محلي للفحص، دون وصول لبيانات حقيقية.
- 4 اختبارات مكونات تفحص إنشاء الشركة بالساعات الصحيحة، وتسميات الإنجليزية، وحوار قبول العرض وتسلسل بياناته، وحجب أزرار القبول والرسوم عن دور الموزع.
- اختبار مستقل يمنع مشاركة مفاتيح ذاكرة استعلامات التوصيل بين حسابين.

تغطي اختبارات القاعدة: الطلب غير المدفوع، إنشاء الشحنة من أصنافها الفعلية، ثبات المبالغ، العناوين/الأوزان/التغطية/الفئات الناقصة، العقد غير الساري، الرفض وسببه وإشعار الإدارة، تكرار الأمر وتعارضه، انتهاء العرض والاستبدال، تعليق الشركة، العزل عبر RPC والقراءات المباشرة، التزامن في الإنشاء والإسناد والقبول، السعة، صلاحيات المندوب مع دور عالمي قديم، ساعات العمل والوردية الليلية، العمولة غير الممولة، تبديل حالة الخدمة، حجب العناوين بعد إعادة الإسناد، وانتهاء العرض أثناء انتظار قفل المعاملة.

## إعادة تشغيل اختبارات القاعدة

تحتاج PostgreSQL قابلاً للتخلص منه على localhost:55432؛ ملف الاختبار ينشئ قاعدة مؤقتة مستقلة ويزيلها بعد التنفيذ. لا تستخدم قاعدة مستضافة أو بيانات إنتاج.

```sh
DELIVERY_TEST_DATABASE_URL=postgres://postgres:YOUR_LOCAL_TEST_PASSWORD@127.0.0.1:55432/postgres npm test
```

استُخدم في بيئة Codex حاوي PostgreSQL المعزول الموجود `sanaa-phase4a-pg` دون منافذ مضيف أو ربط ملفات. يصل الاختبار إليه عبر قناة docker exec للاتصال المحلي فقط:

```sh
DELIVERY_TEST_DATABASE_URL=postgres://postgres:YOUR_LOCAL_TEST_PASSWORD@127.0.0.1:55432/postgres DELIVERY_TEST_DOCKER_CONTAINER=sanaa-phase4a-pg npm test
```

هذه اختبارات فعلية لـPostgreSQL وRLS بتغيير هوية `auth.uid()` في معاملات الاختبار؛ ليست اختبارات توقيع JWT أو تسجيل دخول Supabase مستضاف. فحوصات المتصفح لا تثبت دورة إدارة/شركة حقيقية مسجلة الدخول. يلزم ذلك بعد تطبيق المهاجرات في Lovable.

## الملفات الأساسية

`src/delivery/`، ومسارات `src/routes/_authenticated/`، وروابط الإدارة والشريط الرئيسي، وملفات اللغات والتنسيق، والمهاجرات الإضافية 0004–0006. لا تعدّل ملفات البناء المولدة أو تحمل مفاتيح خادمية إلى المتصفح.

استُخدم القفل التشغيلي الحالي لمنع تعارض الإسناد والسعة؛ مناسب لهذه الدفعة اليدوية، ويحتاج قياساً وتطويراً عند التوسع. انتهاء العرض يمنع القبول فوراً عند التحقق، مع إعادة إسناد إدارية؛ لا يوجد ادعاء بوجود عامل خلفي آلي لإعادة الإسناد.
