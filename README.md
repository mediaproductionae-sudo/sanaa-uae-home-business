# صَنْعة | منصة الأعمال المنزلية

المرحلة الأولى: نظام تصميم وصفحة رئيسية عربية RTL لمنصة المشاريع المنزلية الإماراتية. **نسخة تجريبية — بيانات وهمية — لا توجد معاملات حقيقية**.

## التشغيل

يتطلب Node.js 20.9 أو أحدث.

```sh
npm ci
npm run dev
npm run typecheck
npm run build
```

يصدر Next.js الصفحة الثابتة إلى `out/`. يمكن استضافتها على أي خادم ملفات ثابتة، أو تشغيلها عبر `npm run dev` أثناء التطوير.

## النطاق المنفذ

صفحة رئيسية متجاوبة، الإمارات السبع، فلاتر وبحث محلي، تفاصيل توضيحية في حوار قابل للإغلاق بلوحة المفاتيح، مفضلة محفوظة على الجهاز، متاجر وقصة خيالية، الثقة والسلامة ودعوة الانضمام. الأزرار المتعلقة بالمراحل التالية تعرض توضيحاً صريحاً بدلاً من الادعاء بأنها تعمل.

لا يوجد تسجيل دخول أو قاعدة بيانات أو Supabase أو مدفوعات. لا تُجمع بيانات شخصية. الأسعار توضيحية. الصورة لا تمثل منتجاً فعلياً معروضاً للبيع.

## الملفات

- `app/page.tsx`: الصفحة والتفاعلات وبيانات العرض.
- `app/globals.css`: نظام الألوان والخطوط والمكونات والتجاوب وتقليل الحركة.
- `app/layout.tsx`: اللغة والاتجاه وبيانات الصفحة.
- `public/images/`: صور توضيحية محفوظة محلياً.
- `docs/design-system.md`: الاتجاهات ونظام التصميم.
- `docs/phase-1-report.md`: تقرير التنفيذ والتحقق والقيود.

توقف التنفيذ بعد المرحلة الأولى وفق الطلب. تتطلب المراحل التالية موافقة منفصلة. لا تنفذ migrations على قاعدة حقيقية دون موافقة.

## التحديث الحالي: الصفحات التفاعلية

أُضيفت صفحات المتاجر والمنتجات والتصنيفات والتفاصيل والمفضلة والسلة والحساب والطلبات والشكاوى ولوحة مقدم الخدمة، باستخدام بيانات ومخزن محلي مشتركين. صفحة الدخول محاكاة وليست مصادقة حقيقية. الطلبات والشكاوى محلية ولا تُرسل إلى أي جهة. راجع docs/navigation-report.md للملفات والمسارات والاختبارات والقيود.

اختبارات الاستخدام: `npm run test:navigation`، الحسابات: `npm run test:accounts`، الروابط: `npm run test:links`، والتجاوب: `npm run test:responsive`، بعد `npm run build`.
